= Technology Stack

This application is developed using these technologies:

- https://nodejs.org/[Node.js] (v22): JavaScript runtime environment.
- https://yarnpkg.com/[Yarn] (v1.22.21): Node.js package manager.
- https://www.typescriptlang.org/[TypeScript] (v6.0.3): JavaScript type support.
- https://reactjs.org/[React] (v19.2.7): JavaScript library for building user interfaces.
- https://nextjs.org/[Next.js] (v16.2.10): Framework for building React-based applications.
- https://getbootstrap.com/[Bootstrap] (v5.1.3): CSS framework.
- https://jestjs.io/[Jest] (v29.7.0): Testing framework.
- https://formik.org/[Formik] (v2.2.7): Form management library.
- https://www.keycloak.org/[Keycloak] (v25.0.6): Authentication system.
- https://github.com/wopian/kitsu[Kitsu] (v8.3.1): JSON:API client.
- https://tanstack.com/table/v8[React Table] (v8.9.3): Table component library.
- https://echarts.apache.org/[ECharts] (v5.6.0): Charting library.
- https://github.com/Esri/esri-loader[ESRI Loader] (v3.3.0): Map integration.
- https://www.docker.com/[Docker]: Application containerization.
