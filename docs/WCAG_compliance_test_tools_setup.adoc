= Accessibility Testing with axe DevTools

To get visual feedback on which HTML elements violate WCAG rules, we recommend using the *axe DevTools* browser extension.

. Download and install the *axe DevTools* extension.
. Launch your target page in your web browser.
. Press `F12` (or right-click and select *Inspect*) to launch your browser's DevTools panel.
. Navigate to the *axe DevTools* tab in the DevTools top menu bar (you may need to click the `>>` icon if your panel is narrow).
. Click the *Scan ALL of my page* button to run the accessibility audit.
. A report is shown for the page detailing WCAG validation failures and the specific elements that have compliance issues.
. Click on a specific issue in the list and use the *Highlight* button to visually locate the exact element directly on the page.
. After fixing a specific issue in your code, click the *Re-run automatic scan* button to verify the issue is gone.
